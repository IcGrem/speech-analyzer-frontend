# Restaurant Management System

Современная система управления рестораном на Vue 3 + Vite.

## 🚀 Технологии

- **Frontend**: Vue 3 + Composition API
- **Build Tool**: Vite
- **UI Framework**: Element Plus
- **Styling**: Tailwind CSS + SCSS
- **State Management**: Pinia
- **Routing**: Vue Router 4
- **Charts**: Chart.js + vue-chartjs
- **Word Cloud**: vue-wordcloud
- **HTTP Client**: Axios
- **Validation**: Vuelidate

## 📁 Структура проекта

```
src/
├── api/           # API клиенты и интерцепторы
├── assets/        # Статические ресурсы (стили, изображения)
├── components/    # Переиспользуемые компоненты
│   ├── Dialogs/   # Диалоговые окна
│   └── icons/     # Кастомные иконки
├── layouts/       # Макеты страниц
├── router/        # Конфигурация маршрутизации
├── store/         # Управление состоянием (Pinia)
├── views/         # Страницы приложения
│   └── auth/      # Страницы авторизации
└── utils/         # Утилиты и хелперы
```

## 🛠 Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build

# Предварительный просмотр сборки
npm run preview
```

## 🔧 Конфигурация

- **Vite**: `vite.config.js` - настройки сборки и плагинов
- **Tailwind**: `tailwind.config.js` - конфигурация CSS фреймворка
- **TypeScript**: `tsconfig.json` - настройки TypeScript
- **PostCSS**: `postcss.config.cjs` - конфигурация PostCSS

## 📝 Особенности

- Автоматический импорт Vue компонентов и API
- Поддержка TypeScript
- Анимации переходов между страницами
- Адаптивный дизайн
- Интерактивные графики и диаграммы
- Облако тегов с анимацией
