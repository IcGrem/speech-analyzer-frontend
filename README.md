# Restaurant Management System

Система управления рестораном с аналитикой диалогов и метриками сотрудников.

## Основные возможности

### Анализ диалогов
- **Таблица диалогов** с пагинацией и фильтрацией
- **Фильтры по дате** - выбор периода для анализа
- **Фильтры по сотрудникам** - выбор конкретных сотрудников
- **Сортировка** по дате записи, общему баллу, имени сотрудника
- **Пагинация** с настраиваемым размером страницы (10, 20, 50, 100)

### API Endpoints

#### Диалоги
- `GET /api/v1/dialogs/get-dialogs` - получение списка диалогов
  - Параметры:
    - `page` - номер страницы (по умолчанию: 1)
    - `size` - размер страницы (по умолчанию: 10, максимум: 100)
    - `start_date` - дата начала фильтра (YYYY-MM-DD)
    - `end_date` - дата окончания фильтра (YYYY-MM-DD)
    - `employee_ids` - список ID сотрудников через запятую
    - `sort_by` - поле сортировки (recording_start_date, overall_score, employee_name)

#### Сотрудники
- `GET /api/v1/employees/get-employees` - получение списка сотрудников

### Структура данных диалога

```json
{
  "id": 1,
  "employee_name": "Иванов Иван",
  "recording_start_date": "2024-01-15",
  "dialog_id": "D001",
  "overall_score": 8.5,
  "top_words": ["продажа", "скидка", "качество", "гарантия", "доставка"],
  "dictionary_match": true
}
```

### Использование

1. **Фильтрация по дате**: Выберите начальную и конечную дату для ограничения периода анализа
2. **Фильтрация по сотрудникам**: Выберите одного или нескольких сотрудников из выпадающего списка
3. **Сортировка**: Используйте заголовки столбцов для сортировки данных
4. **Пагинация**: Переключайтесь между страницами и изменяйте размер страницы

### Технические детали

- **Frontend**: Vue 3 + Composition API
- **State Management**: Pinia
- **UI Components**: Element Plus
- **Styling**: Tailwind CSS + SCSS
- **Internationalization**: Vue I18n (русский язык)

## Установка и запуск

```bash
npm install
npm run dev
```
